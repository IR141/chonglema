# 冲了吗 1.1

纯本地自律打卡 App，不联网、不申请任何权限，所有记录只存在本机 SQLite。

## 本次更新

- **挑战重写**：从点击开始的那一刻起，接下来 N 天每天都不许有「冲了」；中途记录立刻中断，删掉那条记录即可复活。结果由记录实时计算。
- **次数配额**：每天 / 每周 / 每月 / 自定义起止，配额 1~999；超过只变红提醒、不禁止记录。保存后卡片自动收起，修改时先「关闭配额」再重设。
- **挑战记录**：成功 / 失败 / 已放弃都会保留，最多 10 条，长按可删除。
- **界面打磨**：挑战成功弹窗精简；失败卡只保留天数选择；首页失败态不显示中断天数；「放弃挑战」「关闭配额」统一为危险按钮 + 二次确认。
- **其他**：类型词条增删 / 拖动排序、主题、搜索、年度报告、JSON 备份导入导出等。

## 安装

下载 `chonglema-v1.1-release.apk`（约 1.7 MB），传到手机点击安装即可。

- 从旧版升级可直接覆盖安装，数据保留；本版 **versionCode 46 / versionName 1.1**。
- 当前 release 使用 debug 签名，方便覆盖升级；如需上架应用商店请自行换正式 keystore。

完整更新记录见 [CHANGELOG.md](https://github.com/IR141/chonglema/blob/main/CHANGELOG.md)。
